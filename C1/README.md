# C1 checkpoint

- `run.md`: procedure, source-to-model mapping, results with named plans, the four
  design lines (operator / index / risk), the verified AI claim, and what is
  deliberately left out. Start here.
- `manifest.tsv`: repo, revision, path, size and SHA-256 of the two source files
  (generated by `scripts/manifest_c1.py`, cross-checked against the Hugging Face record).
- `evidence/`: generated by `scripts/verify_c1.py`:
  - `verification.txt`: counts, duplicate/orphan checks, FK validation, before/after comparison.
  - `fts_results_before.tsv`, `fts_results_after.tsv`: complete ordered `(chunk_id, document_id)` pairs.
  - `explain_before.txt`, `explain_after.txt`: basic PostgreSQL plans.
  - `index_info.txt`: GIN definition and size.
  - `literal_comparison.txt`: FTS versus `ILIKE` for `flight`, `flights`, `preflight`.
  - `ai_claim_check.txt`: substring counts and verdict for the AI claim in `run.md`.

Related sources: `sql/01_c1_schema.sql` (DDL), `sql/02_c1_queries.sql` (search SQL),
`sql/03_c1_checks.sql` (integrity checks), `scripts/` (download, manifest, sample,
import, verify). The source data itself is excluded from Git; only identifiers,
aggregates, plans and definitions are stored here.
